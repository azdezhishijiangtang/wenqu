# 问渠 · 高中理科 AI 答疑

面向高中数学、物理、化学、生物的 AI 答疑与学习网站。

**本站是纯前端静态应用，没有后端、没有账号体系、不收集任何数据。** 解题 API Key 由用户自己填写，只保存在浏览器本地；图片文字识别由浏览器本机的 Tesseract.js 完成。

## 功能

- 四科 AI 答疑：三种模式（启发式 / 完整讲解 / 应试速解），支持流式输出与推理过程折叠展示。
- 图片题：粘贴或上传最多 3 张题图，浏览器本机 OCR 提取文字，人工核对后再交给文字模型。
- 知识手册：四科公式与规律速查，支持筛选与复制 LaTeX。
- 错题本：记录题目、错因、正确思路与掌握状态，可带着错因再问 AI。
- 学习计划：按周任务、完成统计与 25 分钟专注计时器。
- 数据与备份：导出 / 导入 JSON 备份，用于换设备或清理浏览器数据前搬运。**导出文件永远不含 API Key。**

## 隐私与数据边界

- 所有对话、错题、计划只存在当前浏览器的 localStorage；清理浏览器数据会一并清掉，请定期导出备份。
- 解题请求由浏览器直接发给你自己配置的模型服务商，不经过本站；本站没有服务器可以中转或保存。
- API Key 只保存在浏览器本地，不写入磁盘备份；不要在公共电脑上保存，用完可点「清除密钥」。
- 图片原图从不上传，只有你核对后的文字会发送给你配置的解题模型。

## 本地开发

```bash
npm ci
npm run dev
```

构建与开发启动前会自动运行 `scripts/prepare-ocr.mjs`，从 npm 依赖复制 Tesseract Worker、WASM 引擎和中英文字库到 `public/ocr/`；资源随静态站点发布，运行时不依赖第三方 CDN。首次识别需加载这些资源。

```bash
npm run build       # tsc -b && vite build
npm run test:app    # 备份与存储的单元测试
```

## 部署

推送到 `main` 后，`.github/workflows/deploy.yml` 会自动构建并把 `dist/` 发布到 GitHub Pages。构建产物是纯静态文件，可部署到任意静态托管。
